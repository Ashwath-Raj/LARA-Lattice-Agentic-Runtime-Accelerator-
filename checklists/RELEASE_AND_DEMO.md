# Release and Demo Checklist

- [ ] Cloud Run URL responds over HTTPS.
- [ ] Workbench and Runtime Console load from same origin.
- [ ] Fresh browser session can log in as Operator.
- [ ] Operator route excludes restricted source.
- [ ] Supervisor route includes source only when policy permits.
- [ ] Research, Analysis and Verification complete the incident workflow.
- [ ] Current SOP revision is used; obsolete SOP is flagged.
- [ ] Evolution failure is reproducible.
- [ ] Candidate evaluation runs live and actual results are shown.
- [ ] Admin approval promotes candidate.
- [ ] Re-run uses promoted version.
- [ ] Simulated maintenance action requires Supervisor approval.
- [ ] Equipment control is denied.
- [ ] Audit trace persists after reload.
- [ ] All deployed components are Google Cloud-hosted.
- [ ] No secret appears in browser devtools or source map.
- [ ] Fallback screen recording available.
