## 1. Comprehensive Operation Contract Matrix

| **Demo Login** | `demoLogin(id)` | `POST /api/v1/auth/demo-login` | `{ principal_id, demo_password: 'demo' }` | `DemoLoginRequest { principal_id: str, password: Optional[str] = "demo-password" }` | `{ principal: Principal }` | `PrincipalResponse { principal_id, display_name, roles, attributes }` | **Payload & Envelope**: Frontend sent `demo_password`; backend expects `password`. | **Logout** | `logout()` | `POST /api/v1/auth/logout` | None (cookie auth) | None (`lara_session` cookie) | `void` (200 JSON) | HTTP 204 No Content | **HTTP Status**: Backend returns 204 without JSON body. | **Health & Readiness** | `getHealth()` | `GET /api/v1/health/ready` | None | None | `SystemHealth { status, firestore, vertex_ai, version }` | `{ "status": "ready" }` | **Semantic Fabrication**: Frontend fabricated `firestore: CONNECTED`, `vertex_ai: READY`. | **Route Resolution** | `resolveRoute(taskId)` | `GET /api/v1/graph/routes/resolve?task_id={id}` | Query `task_id` | Query `task_id` | `RouteResult { route_id, selected_sources, ... }` | `RouteResolveResponse { task_id, principal_id, permitted_sources, permitted_tools, selected_path, excluded_candidates, score_components, graph_version }` | **Field Naming**: Backend returns `permitted_sources` and `selected_path`; does not return `route_id` or `selected_sources`. | Praneeth | Map `route_id` from `task_id + graph_version`, and derive `selected_sources` as sources appearing in `selected_path`. |
| **Graph Nodes & Edges** | `getGraphNodes()`, `getGraphEdges()` | `GET /api/v1/graph/topology` | None | **ENDPOINT DOES NOT EXIST** | `GraphNode[]`, `GraphEdge[]` | `404 Not Found` / No route | **Missing Route**: Backend `graph.py` exposes route resolution only; topology is held in internal NetworkX graph. | Ashwath | Request read-only `GET /api/v1/graph/topology` from Ashwath. ## 2. Mock-Only Method Inventory

The following API client methods currently read or write local state because backend routes are not implemented:

1. `getRecentTasks()`: No backend `GET /api/v1/tasks` route.
2. `getGraphNodes()`, `getGraphEdges()`: No backend graph topology route.
3. `getAgents()`, `getAgent()`: No backend agent registry routes.
4. `getApprovals()`: No backend `GET /api/v1/approvals` queue route.
5. `rollbackCandidate()`: No backend rollback route.
